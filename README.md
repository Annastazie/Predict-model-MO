
## Описание проекта

`Predict-model-MO` — это MVP интеллектуальной системы прогнозирования итогового балла муниципального образования на основе агрегированных квартальных данных по 8 сферам деятельности.

Система сочетает методы машинного обучения и интерактивный пользовательский интерфейс, позволяя анализировать и прогнозировать результаты деятельности муниципальных образований.

---

## Цель проекта

Цель проекта — разработка прототипа системы, позволяющей:

- прогнозировать итоговый балл муниципального образования;
- сравнивать фактические и прогнозные значения;
- анализировать структуру показателей по сферам;
- визуализировать результаты в удобном интерфейсе.

---

## 🏛 Бизнес-контекст

Проект ориентирован на задачу оценки эффективности муниципальных образований.

В текущем процессе итоговый балл рассчитывается постфактум, что ограничивает возможности оперативного управления.

Разработанный MVP позволяет перейти от ретроспективного анализа к прогнозной аналитике и использовать исторические данные для предварительной оценки результата.

---

## 📊 Используемые данные

В проекте используются обезличенные данные за **3 квартала 2024 года**.

Каждое наблюдение соответствует одному муниципальному образованию в конкретном квартале.

### Входные признаки:
- `sphere_1` – `sphere_8` — агрегированные показатели по сферам

### Целевая переменная:
- `total_score` — итоговый балл

### Дополнительные признаки:
- `quarter_num`
- `avg_sphere_score`
- `min_sphere_score`
- `max_sphere_score`
- `weak_spheres_count`

## Использованные модели

В проекте реализованы и сравнены:

- **Baseline_mean** — прогноз среднего значения;
- **LinearRegression_basic** — линейная регрессия на базовых признаках;
- **RandomForest_extended** — случайный лес на расширенных признаках.

### Особенности:
- для линейной модели применено масштабирование (StandardScaler);
- для Random Forest выполнен подбор гиперпараметров (GridSearchCV).

---

## Метрики качества

Для оценки моделей использованы:
- **MAE** — средняя абсолютная ошибка  
- **RMSE** — среднеквадратичная ошибка  
- **MAPE** — относительная ошибка (с защитой от деления на 0)

---

## Результаты

Лучшая модель:
- **RandomForest_extended**

Метрики:
- MAE: 0.369  
- RMSE: 0.543  
- MAPE: 1.77%

Интерпретируемая модель:
- **LinearRegression_basic**

- MAE: 0.760  
- RMSE: 0.924  
- MAPE: 3.38%

## Развертывание проекта
Проект реализован как локальное веб-приложение.
Для запуска необходимо:

1. Установить зависимости:
pip install -r requirements.txt

2. Запустить интерфейс:
streamlit run app.py

3. Открыть в браузере:
http://localhost:8501

Приложение автоматически загружает:
- подготовленный датасет;
- обученные модели;
- и предоставляет интерфейс для прогнозирования.


## Ограничения
- небольшой объем данных (3 квартала);
- агрегированные показатели;
- отсутствует интеграция с внешними системами;
- интерфейс носит демонстрационный характер.
